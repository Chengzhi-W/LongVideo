# Locked UltraVideo-Long 5K selection

`selection_ids.csv` contains only the deterministic clip IDs and split. Full
metadata/captions are deliberately omitted and must be read from the official
`APRIL-AIGC/UltraVideo-Long` dataset by the downloader.

- 5,000 clips: 4,900 train and 100 validation
- 960p archive family
- source duration at least 15.6 seconds
- selection seed 42
- selection SHA-256:
  `266445a139fc005372433bfd6878b5ee808b19d744388886b9186a1560af69ff`
